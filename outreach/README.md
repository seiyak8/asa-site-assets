# 学校向け営業メールの差し込み送信

KOJIMA JAPAN CUP の参加募集を、バンコクの学校へ日本語・英語・タイ語で送るための仕組み。

- `bangkok-schools.csv` … 名簿の下書き（**アドレスはほぼ未確定**）
- `../line-bot/Outreach.gs` … 送信スクリプト（Apps Script）

---

## 最初に：アドレスは私が用意できない

この環境からは外部サイトを読めない（`isat.or.th` も学校の公式サイトも
ネットワークポリシーで遮断）。Web検索の断片から拾えたのは4校分だけで、
残りを `athletics@学校名.ac.th` のように**推測で埋めることはしない**。

理由は単純で、宛先不明のバウンスが増えると送信ドメインの評価が下がり、
その後に送る正規のメールまで迷惑メールへ振り分けられるようになる。
1回の営業のために、ASAのメールが今後届かなくなるのは割に合わない。

**アドレスの確定は人が行うこと。** 各校の公式サイトの Contact ページで
1件ずつ確認するのが確実。

## 宛先は入学課ではなく体育科へ

検索で出てくるのは `admissions@`（入学課）が中心だが、**サッカー大会の案内を
入学課に送っても、まず読まれない**。入学課の仕事は入学希望者への対応であって、
課外活動の受付ではない。

適切な宛先は次のいずれか。インター校の多くは専用アドレスを持っている。

- `athletics@` / `sports@` / `pe@` … 体育科・アスレチックディレクター
- `activities@` / `cca@` … 課外活動担当
- 見つからなければ代表アドレス宛に「体育科ご担当者様」と明記して送る

`bangkok-schools.csv` に入っている4件は入学課宛なので、体育科の宛先が
分かり次第そちらへ差し替えること。

## タイのローカル校は別の手段が要る

タイの公立・私立校はメールアドレスを公開していないことが多く、連絡手段が
電話や Facebook ページに偏っている。インター校と同じ一斉送信では届かない。

現実的な進め方は、まずインター校へメールで当たり、ローカル校は
既存の繋がり（コーチ、保護者、提携先）を辿るか、電話・LINE で個別に当たる。
名簿に無理にローカル校を並べても、送れないアドレスが増えるだけになる。

---

## 使い方

1. 名簿のスプレッドシートを用意する

   作成済み：**[ASA 学校営業リスト（KOJIMA JAPAN CUP）](https://docs.google.com/spreadsheets/d/1_oDl26YsPogLJLXrJkJo1gBVw1TjWOBhPHlotmLGwVE/edit)**
   （`bangkok-schools.csv` の内容がそのまま入っている）

   Apps Script のプロジェクトの設定 → スクリプトプロパティに
   `OUTREACH_SHEET_ID` = `1_oDl26YsPogLJLXrJkJo1gBVw1TjWOBhPHlotmLGwVE` を追加する。
   未設定だと LINE 用のスプレッドシートを見にいくので、必ず入れること。

   タブ名は `Outreach` でなくてもよい。1行目が上記の見出しどおりなら
   「シート1」のままでも認識する。

2. アドレスと言語（`ja` / `en` / `th`）を人が確認して入力
3. `previewOutreach()` … 1通目の本文を実物どおりに表示。**必ず目で読む**
4. `sendOutreachBatch()` … `DRY_RUN = true` のまま実行。宛先一覧がログに出るだけで、1通も送られない
5. 問題なければ `Outreach.gs` 先頭の `DRY_RUN` を `false` に変えて再実行
6. `outreachStatus()` … どこまで送ったか集計

### 列

| 列 | 内容 |
|---|---|
| `schoolName` | 差し込む学校名。本文の「◯◯校 ご担当者様」に入る |
| `email` | 送信先。空欄の行は自動でスキップ |
| `lang` | `ja` / `en` / `th` |
| `contact` | 担当部署・担当者名（メモ用途） |
| `status` | 空欄=未送信 / `sent` / `skipped` / `error` |
| `sentAt` | 送信日時 |
| `note` | 失敗理由や備考 |

`status` に `skipped` と書いておけば、その行は永久に送られない。
送りたくない学校はこれで除外する。

## 安全のための作り

**既定では1通も送らない。** `DRY_RUN = true` が初期値。対外的な一斉送信は
間違えたときの損害が大きいので、空撃ちで確認してからでないと本番に進めない。

**1回の実行で40通まで。** Gmailの1日あたり上限（Workspace 2,000通 /
無料アカウント 500通）に一度に当たらないよう刻んである。続きは再実行すれば
未送信の行から再開する。

**二重送信をしない。** `status` が `sent` の行は飛ばす。加えて、同じアドレスが
複数行にあっても1回しか送らない。学校名の表記ゆれで同じ宛先が重複していても、
相手に2通届くことはない。

**送信間隔を空ける。** 1通ごとに1.2秒待つ。

**オプトアウト文を全言語に入れてある。** 「不要であれば返信してください」の一文。
冷たい営業メールでこれが無いのは相手に失礼だし、迷惑メール報告の原因にもなる。

## 自動トリガーは設定していない

時間になったら勝手に送る形にはしていない。名簿の内容が正しいという前提が
崩れたとき、無人だと止められないため。**送るときは人が実行すること。**

締切（8月31日）まで日があるので、40通ずつ数日に分けて送り、返信の様子を
見ながら進めるのが安全。

## 文面を直すには

`Outreach.gs` の `OUTREACH_SUBJECT` と `OUTREACH_BODY` のブロックだけを触ればよい。
`{{SCHOOL}}` が学校名に置き換わる。

3言語とも以下を含む：優勝チームの日本遠征（費用は全額主催者負担）、
大会概要（9月20日・32チーム・7人制・選手12名＋コーチ2名・3,000バーツ）、
申込フォーム、8月31日締切、オプトアウト文。
